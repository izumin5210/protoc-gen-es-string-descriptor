# @bufbuild/protoplugin 調査

## パッケージ構成

| パッケージ | バージョン | 役割 |
|-----------|-----------|------|
| `@bufbuild/protobuf` | 2.11.0 | protobuf ランタイム |
| `@bufbuild/protoplugin` | 2.11.0 | protoc プラグイン作成フレームワーク |
| `@bufbuild/protoc-gen-es` | 2.11.0 | protobuf-es コード生成プラグイン |

## Plugin インターフェース

```typescript
interface Plugin {
  name: string;
  version: string;
  run(request: CodeGeneratorRequest): CodeGeneratorResponse;
}
```

`Plugin.run()` は同期的に `CodeGeneratorRequest` を受け取り `CodeGeneratorResponse` を返す。

## runNodeJs の仕組み

```
stdin (binary)
  → fromBinary(CodeGeneratorRequestSchema, data)
  → plugin.run(req): CodeGeneratorResponse
  → toBinary(CodeGeneratorResponseSchema, res)
  → stdout (binary)
```

1. `process.stdin` からバイナリデータを全て読み取る
2. `fromBinary()` で `CodeGeneratorRequest` にデシリアライズ
3. `plugin.run(req)` を呼び出し
4. `toBinary()` で `CodeGeneratorResponse` をシリアライズ
5. `process.stdout` に書き出し

## protocGenEs のエクスポート

```typescript
// @bufbuild/protoc-gen-es
export declare const protocGenEs: import("@bufbuild/protoplugin").Plugin;
```

`protocGenEs` は `Plugin` インターフェースを実装したオブジェクトとしてエクスポートされている。

bin ファイル:
```javascript
#!/usr/bin/env node
const { runNodeJs } = require("@bufbuild/protoplugin");
const { protocGenEs } = require("../dist/cjs/src/protoc-gen-es-plugin.js");
runNodeJs(protocGenEs);
```

## 生成コードの形式

protoc-gen-es が生成する典型的な `_pb.ts` ファイル:

```typescript
// @generated by protoc-gen-es v2.11.0 with parameter "target=ts"
// @generated from file example.proto (package example, syntax proto3)
/* eslint-disable */

import type { GenFile, GenMessage } from "@bufbuild/protobuf/codegenv1";
import { fileDesc, messageDesc } from "@bufbuild/protobuf/codegenv1";
import type { Message } from "@bufbuild/protobuf";

export const file_example: GenFile = /*@__PURE__*/
  fileDesc("CgxleGFtcGxlLnByb3RvEgdleGFtcGxl...");

export const UserSchema: GenMessage<User> = /*@__PURE__*/
  messageDesc(file_example, 0);

export type User = Message<"example.User"> & {
  firstName: string;
  lastName: string;
};
```

## fileDesc() の実装

```typescript
function fileDesc(b64: string, imports?: DescFile[]): DescFile;
```

内部処理:
1. base64 デコード → バイナリバイト列
2. `fromBinary(FileDescriptorProtoSchema, bytes)` でデシリアライズ
3. JSON 名の復元 (`restoreJsonNames`)
4. 依存関係の再構築
5. `FileRegistry` を作成し `DescFile` を返す

## embedFileDesc() によるエンベッド処理

コード生成時に `embedFileDesc()` が呼ばれる:

1. `FileDescriptorProto` をクローン
2. `dependency` フィールドをクリア（ランタイムで復元）
3. `sourceCodeInfo` フィールドをクリア（不要）
4. デフォルト JSON 名を除去（ランタイムで復元）
5. `toBinary()` でシリアライズ
6. `base64Encode(bytes, "std_raw")` で base64 エンコード（標準 base64、パディングなし）

## ラッピングパターン

`protocGenEs` は `Plugin` インターフェースを実装しているため、以下のようにラップできる:

```typescript
import { protocGenEs } from "@bufbuild/protoc-gen-es";
import { runNodeJs } from "@bufbuild/protoplugin";

const plugin: Plugin = {
  name: "protoc-gen-es-string-descriptor",
  version: "0.0.0",
  run(request: CodeGeneratorRequest): CodeGeneratorResponse {
    // 1. オリジナルのプラグインを実行
    const response = protocGenEs.run(request);

    // 2. レスポンスのファイル内容を後処理
    for (const file of response.file) {
      if (file.content) {
        file.content = transformFileDescriptors(file.content);
      }
    }

    // 3. 変更後のレスポンスを返す
    return response;
  }
};

runNodeJs(plugin);
```

## CodeGeneratorResponse の構造

```typescript
// response.file の各エントリ
interface CodeGeneratorResponse_File {
  name?: string;      // 出力ファイルパス
  content?: string;   // 生成コード
  insertionPoint?: string;
}
```

## テスト時の利用

テストでは `runNodeJs` を使わず、直接 `plugin.run(request)` を呼ぶことで、stdin/stdout を介さずに生成結果を検証できる:

```typescript
import { fromBinary } from "@bufbuild/protobuf";
import { CodeGeneratorRequestSchema } from "@bufbuild/protobuf/wkt";

// テスト用のリクエストバイナリから CodeGeneratorRequest を作成
const request = fromBinary(CodeGeneratorRequestSchema, requestBytes);
const response = plugin.run(request);

// response.file を検証
```
