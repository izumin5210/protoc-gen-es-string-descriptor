**BREAKING:** emit descriptors as length-less nested arrays with name-based references.

Generated code changes shape: `fileDesc(tree, imports)` takes the descriptor as nested arrays without length prefixes, with oneof members and public / weak imports marked by name inside the descriptor, and imports one per line. `messageDesc`, `enumDesc`, `serviceDesc` and `extDesc` refer to elements by name and are imported from this package. `.ts` and `.d.ts` files get a type keyed by number per message and enum, so that duplicate numbers fail type checking.

Regenerate all code and upgrade the runtime together. Code generated by 0.1 keeps working with the new runtime. `@bufbuild/protobuf` and `@bufbuild/protoc-gen-es` 2.5.0 or later are required.
